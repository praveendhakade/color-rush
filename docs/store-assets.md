# Google Play listing checklist

- [ ] App name
- [ ] Short description
- [ ] Full description
- [ ] Adaptive app icon
- [ ] Feature graphic
- [ ] Phone screenshots from the final Android build
- [ ] Privacy policy URL, after legal/product review
- [ ] Content rating questionnaire
- [ ] Target audience declaration
- [ ] Data safety form, verified against the final build
- [ ] Category
- [ ] Contact email and website (if applicable)

Do not publish legal, privacy, or data-safety claims until they have been reviewed against the released app and current Google Play requirements.
